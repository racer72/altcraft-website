# altcraft-website

The AltCraft website **plus** the crew collaboration space.

## Website

Static site — open `index.html` in a browser, or serve the folder any way you like.

- `index.html` — single-page site: hero, build gallery, crew, commissions
- `styles.css` — black + safety-orange grunge theme
- `assets/` — site images (hero art, etc.)

To publish free: GitHub Pages — repo Settings → Pages → deploy from the `main` branch.
The site then lives at `https://racer72.github.io/altcraft-website`.

## Collab space (Morgan ↔ Roger ↔ Slim)

- **`designs/`** — Morgan's design briefs. One markdown file per project,
  following `_template.md`. Reference images live next to the brief.
- **`build-queue.md`** — the live build status board. Slim keeps it updated.
- **`posts/`** — Instagram post drafts, following `_template.md`.
  Roger approves every post before it goes up. No exceptions.
- **`shop-notes/`** — build reports and lessons learned.

The loop: Morgan briefs → Roger builds → Slim posts. The repo is the source of truth.
